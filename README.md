# 百变虚拟角色

**v0.1.0 · 本地网页应用 · 中文界面 · MIT 开源**

输入角色名字建立分层资料库，或创建自己的角色，与 DeepSeek 驱动的文字角色聊天。角色有偏好、判断与边界；本项目通过资料和提示约束对话，不训练模型参数，也不保证完全还原原作。

## 快速启动

1. 安装 [Node.js](https://nodejs.org/)（22 或更高版本；本次验证使用 24）。
2. 下载源码 ZIP，解压到一个文件夹。
3. Windows 双击 `start.cmd`；或在该文件夹打开终端，执行 `npm start`。
4. 浏览器打开 **http://127.0.0.1:3210**，保持后台运行。停止时在终端按 Ctrl+C。

**没有第三方运行依赖，无需执行 npm install。** macOS/Linux 可使用上述终端命令，但本版本尚未在这两个系统实测。不要直接双击 index.html。

未填写密钥时为明确标注的演示模式，使用固定回复，不能理解问题。真实聊天在“连接设置”填写自己的 DeepSeek API 密钥。密钥只保存在当前后台进程内存，重启后需重新填写。不要把密钥填进源码或提交到 GitHub。

## 功能

- 中文聊天、多个独立角色、本地聊天记录、备份导入导出。
- 模型知识生成、百科检索、Tavily 全网检索、自定义角色。
- 身份只读、核心人格保护、互动设定可修改；核心修改创建独立分支。
- 动机、矛盾、情绪、语言风格、情境示例与来源标注。

| 生成方式 | 需要的密钥 | 说明 |
| --- | --- | --- |
| 模型已有知识 | DeepSeek | 不联网核实，无搜索服务费用 |
| 百科检索 | DeepSeek | 后台连接维基百科，受网络可达性影响 |
| 全网检索 | DeepSeek、Tavily | 搜索人物与对白资料，再由模型分析 |
| 自定义 | 创建时无需密钥 | 真实聊天仍需 DeepSeek |

参考 [配置示例](config.example.json) 和 [详细使用说明](使用说明.md)。配置示例是页面填写指南，程序**不会自动读取这个文件或 .env**。

## 数据与费用

角色和聊天记录存放在当前浏览器的 localStorage，未加密；清理浏览器数据可能丢失记录。保持相同浏览器和网址并定期导出。备份包含对话，分享前自行检查。

真实聊天会向 DeepSeek 发送当前角色档案和最近的聊天上下文。检索会向 Wikipedia 或 Tavily 发送角色名和作品信息，检索结果随后交给 DeepSeek。没有遥测、登录系统或开发者代付额度。详见 [隐私与安全说明](SECURITY.md)。

API 服务按用户账户用量计费，具体价格以服务商为准。当前生成最多输出 5500 token，聊天最多 700 token，每次后台启动最多 100 次模型请求；这些不是金额上限。全网生成通常另有两次搜索调用。不要将此本地后台直接部署到公网。

## 开发与检查

```sh
npm test
npm run check:privacy
```

测试使用虚构数据与模拟服务，只连接本机测试端口，不使用真实密钥或产生 API 费用。发布检查见 [发布指南](docs/RELEASING.md)，参与开发见 [贡献说明](CONTRIBUTING.md)。

```text
server.cjs             本地服务、密钥与模型请求

knowledge.cjs          模型知识生成

app.js / index.html / style.css  浏览器界面
tests/                 无付费调用的回归测试
scripts/               发布隐私检查
```

## 已知限制

这是早期版本，不含桌面安装包、移动端、语音、直播或区块链。模型可能记错角色，提示约束不能完全防止性格偏离；网页文字匹配也不能证明台词说话者或语境正确。对话只发送有限上下文，并非无限长期记忆。真实服务可用性和主观角色表现不由模拟测试保证。
